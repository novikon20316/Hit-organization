# Release Notes — v1.0.0 (Initial Release)

Paste the relevant language version into the Play Console "What's new" field for this release.

## English

Initial release of HIT Projects.

- Track final-year project milestones and timelines
- Real-time chat with your supervisor, examiners, and coordinator
- Push notifications for updates, documents, and defense scheduling
- Secure sign-in with two-factor authentication (2FA)
- Role-based dashboards for students, supervisors, examiners, and coordinators
